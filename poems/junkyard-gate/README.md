# c cure

A dictation, kept nearly whole, set behind a gate. Five movements.

`index.html` is the scene — open it in a browser and click the gate. Nothing is
fetched; it's one file with no dependencies, and the links that came with the
dictation are quoted as text, never loaded.

    python3 -m http.server -d . 8000   # then visit /poems/junkyard-gate/

Switch movements with the `i` / `ii` / `iii` / `iv` / `v` controls bottom-left, or
`←` / `→` to cycle (`1` / `2` / `3` / `4` / `5` to jump). `Esc` closes the gate.

| file | what it is |
| --- | --- |
| `poem.txt` | movement i, as set |
| `poem-ii.txt` | movement ii, as set |
| `source-ii.txt` | movement ii's raw dictation, verbatim, links included |
| `poem-iii.txt` | movement iii, as set |
| `source-iii.txt` | movement iii's raw dictation, verbatim |
| `poem-iv.txt` | movement iv, as set |
| `poem-v.txt` | movement v, as set |

## editing notes

Movement i: line breaks, punctuation, and one verb (`if it had to be a junkyard /
let it have a gate` — the dictation had "had to be a junk yard with a gate").
Every image is the transcription's own.

Movement ii: line breaks and punctuation only. `everytime` → `every time`,
`toknow` → `to know`. The garbled stretch (`wherever it else it delivered`,
`the way it had been congruent with / it needed to be done`) is left exactly as
dictated — it reads as a machine describing itself in the grammar of a spec, and
smoothing it would lose the only thing it says. The last line stops mid-clause
because the dictation did.

Movement iii: line breaks and punctuation only. `crys` and `fucken` are left as
dictated — the truncation is the point, and "crystal" spelled out would break
the register the movement is made of. The last line is set apart because it
turns the whole movement around: the thing nobody asked for was still asked for.

Movement iv: the original line breaks are kept; the later addition is broken
into lines. `KneW`, `Ans`, `neen`, and `everytime` are left as given.

Movement v: the words and punctuation are kept as given; line breaks open the
repetition up for reading. The optional field notes in the scene offer ways to
think, act, and express alongside each movement, separate from the poems.
