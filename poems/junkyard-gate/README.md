# cure

A dictation, kept nearly whole, set behind a gate.

`poem.txt` is the text. `index.html` is the scene — open it in a browser and
click the gate. Nothing is fetched; it's one file with no dependencies.

    python3 -m http.server -d . 8000   # then visit /poems/junkyard-gate/

Editing notes: the liberties are line breaks, punctuation, and one verb
("if it had to be a junkyard / let it have a gate" — the dictation had "had to
be a junk yard with a gate"). Every image is the transcription's own.
